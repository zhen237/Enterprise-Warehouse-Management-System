## 前端目录结构

```
frontend/
├── index.html                               # HTML 入口

    │
    ├── components/                          # 公共组件
    │   └── Layout.vue                       # 主布局（侧边栏+顶栏+内容区）

    ├── store/                               # 状态管理

        ├── Outbound.vue                     # 出库管理
        ├── Check.vue                        # 库存盘点
```

## 业务模块对应关系

| 模块 | 后端 Controller | 前端页面 | API 前缀 |
|------|----------------|---------|----------|
| 系统管理 | AuthController | Login.vue | /api/auth |
| 物资管理 | ProductController | Products.vue | /api/products |
| 仓库管理 | WarehouseController | Warehouses.vue | /api/warehouses |
| 库存查询 | InventoryController | Inventory.vue | /api/inventory |
| 入库管理 | InventoryController | Inbound.vue | /api/inventory |
| 出库管理 | InventoryController | Outbound.vue | /api/inventory |
| 库存盘点 | InventoryController | Check.vue | /api/inventory |
| 数据统计 | DataController | Reports.vue | /api/data |
| 首页仪表盘 | — | Dashboard.vue | 聚合多个接口 |

## 数据库表对应关系

| 数据表 | 实体类 | 说明 |
|--------|--------|------|
| user | User.java | 用户表（admin/Admin@123 默认账号） |
| supplier | Supplier.java | 供应商表 |
| product | Product.java | 商品表（软删除 enabled） |
| warehouse | Warehouse.java | 仓库表 |
| inventory | Inventory.java | 库存表（商品-仓库-数量关系） |
| inbound_record | InboundRecord.java | 入库记录表（RK 单号） |
| outbound_record | OutboundRecord.java | 出库记录表（CK 单号） |
| inventory_check | InventoryCheck.java | 盘点记录表（PD 单号） |

## 三层架构说明

```
┌──────────────────────────────────────────────┐
│              表示层（View）                    │
│  Vue 3 + Element Plus + ECharts              │
│  负责用户交互和页面渲染                        │
├──────────────────────────────────────────────┤
│              控制层（Controller）              │
│  Spring Boot REST API                        │
│  接收请求、参数校验、调用 Service              │
├──────────────────────────────────────────────┤
│              业务层（Service）                │
│  Spring Bean + @Transactional                │
│  核心业务逻辑：两步确认制、库存校验等          │
├──────────────────────────────────────────────┤
│              数据层（Repository）             │
│  Spring Data JPA + MySQL                    │
│  提供 CRUD 和自定义查询                        │
└──────────────────────────────────────────────┘
```
